# Lovable import instructions

Import the `lovable-app` folder through GitHub, then paste the root `LOVABLE_MASTER_PROMPT.md` into Lovable.

Connect Supabase from the Lovable project settings. Apply the SQL migration, then ask Lovable to generate typed Supabase client bindings. The starter UI runs in demo mode and does not expose Swan or Adyen credentials.

Do not connect production provider credentials until Swan and Adyen approve the programme, callback URLs, webhook authentication and security model.

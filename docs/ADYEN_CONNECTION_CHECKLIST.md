# Adyen connection checklist

- Platform/acquiring commercial model agreed.
- Test API key, HMAC key and merchant account received.
- Hosted or component merchant onboarding selected.
- Legal entity, account holder, store and capability mappings completed.
- Payment session and payment link integration implemented.
- Capture, cancellation, full refund and partial refund tested.
- Chargeback and dispute states mapped.
- Settlement and payout reconciliation implemented.
- Tap to Pay device, staff, store and SDK flows agreed.
- Adyen webhook HMAC validation tested.
- Payment, refund, chargeback, transfer and capability events tested.
- Production certification and pilot acceptance completed.

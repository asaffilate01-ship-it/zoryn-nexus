# Swan connection checklist

- Partner agreement and programme configuration agreed.
- Sandbox application credentials received.
- Onboarding mode agreed: hosted link, embedded components or API orchestration.
- Individual and company onboarding payload mappings completed.
- Legal representative and beneficial-owner mappings completed.
- Required actions mapped to Zoryn UI states.
- Account holder, account, IBAN and membership resources mapped.
- Balance and transaction synchronisation implemented.
- SEPA transfer consent/SCA journey implemented.
- Card product, ordering, activation, freeze, replacement and cancellation implemented.
- Swan webhook authentication and replay protection validated.
- Transaction booked, enriched, reversed and returned scenarios tested.
- Production legal wording approved by Swan.

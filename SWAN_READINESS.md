# Security baseline
- MFA and step-up authentication for admin and sensitive customer actions
- Supabase RLS and least-privilege service roles
- Secure HTTP-only sessions where server sessions are used
- CSP, HSTS, frame and MIME protections
- Webhook signature verification and idempotency
- PII masking in operations UI
- Audit every admin mutation
- Secrets in managed secret storage only
- SAST, dependency scanning, backups, incident response and penetration testing before production
